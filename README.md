The SuluArticleViewDocumentBundle is an official Sulu bundle that provides a BC layer for the article-view documents.
They were removed in 3.0 and this bundle provides a way to use them in Sulu 3.0+.

## 🚀&nbsp; Installation and Documentation

Execute the following [composer](https://getcomposer.org/) commands to add the bundle to the dependencies of your
project:

```bash
composer require sulu/article-view-document-bundle
```
